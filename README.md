# Lumen Landing Page

Landing Page giới thiệu Lumen, được xây dựng với MDBootstrap và thiết kế responsive cho máy tính, máy tính bảng và điện thoại.

## Tính năng

- Navbar responsive trên thiết bị di động.
- Hero section với nút kêu gọi hành động.
- Khu vực giới thiệu lợi ích và quy trình sử dụng.
- Hiệu ứng hover, cuộn trang và thay đổi navbar khi cuộn.
- Liên kết đăng ký tài khoản qua `register.html`.

## Cấu trúc file

```text
index.html   Trang Landing Page chính
style.css    CSS tùy chỉnh
script.js    JavaScript cho tương tác giao diện
```

## Cách chạy

Mở trực tiếp file `index.html` bằng trình duyệt.

Các thư viện MDBootstrap, Bootstrap, Font Awesome và Google Fonts được tải qua CDN, vì vậy cần kết nối Internet để hiển thị đầy đủ giao diện.

## Công nghệ sử dụng

- HTML5
- CSS3
- JavaScript
- MDBootstrap 4.19.1
